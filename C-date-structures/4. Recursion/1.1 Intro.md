## Recursion — The "Function That Calls Itself"

### Step 1 — Big Idea 🧠

**What is the one idea this topic is trying to teach?**

> **"A function can solve a big problem by solving a smaller version of the exact same problem."**

Instead of using a loop to repeat an action, you let the **function call itself** until it reaches a simple "base" case that it knows how to solve directly.

---

### Step 2 — Mental Models 💡

**1. The Russian Doll (Matryoshka)**

Imagine a set of dolls nested inside each other. To open the smallest doll, you must open the outer doll, then the next, then the next... until you reach the smallest one. Once you open the smallest one, you can close them all back up.

- **Recursive call** = Opening a doll.
- **Base case** = The smallest doll (you stop here).
- **Returning** = Closing the dolls back up.

**2. The Stack of Plates**

Every time a function calls itself, a new "plate" (frame) is pushed onto the call stack with its own set of variables. When the base case is reached, each plate is popped off one by one, returning values back up the chain.

You already understand stacks from your previous lesson. Recursion uses the **same stack** — the call stack.

---

### Step 3 — The Three Rules of Recursion

| Rule | What it means |
| :--- | :--- |
| **1. Base Case** | A condition that stops the recursion. Without it, the function calls itself forever (stack overflow). |
| **2. Progress** | Each recursive call must move closer to the base case. |
| **3. Self-Call** | The function must call itself with a smaller or simpler version of the original problem. |

---

### Step 4 — The Classic Example: Factorial (Design First)

**Factorial** means multiplying all numbers from 1 to n.

| Concept | Value |
| :--- | :--- |
| Factorial of 5 | `5 × 4 × 3 × 2 × 1 = 120` |
| Factorial of 4 | `4 × 3 × 2 × 1 = 24` |
| Factorial of 1 | `1` |

**The pattern:**
```
factorial(5) = 5 × factorial(4)
factorial(4) = 4 × factorial(3)
factorial(3) = 3 × factorial(2)
factorial(2) = 2 × factorial(1)
factorial(1) = 1   (BASE CASE)
```
